Safety: defenses that work

  • Injection blocked in code before the model ($0); subtle attempts caught by the Grader 3/3
  • Hidden instructions in pasted text are quarantined ("report $9 billion" removed)
  • Invented facts: fact-checker caught 3/20 bad claims → prompt fix → 66/66 verified
  • No wrong actions: read-only tools, drafts only
  • Budgets: 6 turns, 60k tokens per run, $1/day cap
  • 15 unit tests pass without an API key
